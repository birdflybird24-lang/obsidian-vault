# 05_Intervention_Patterns

## 用途
支援介入のパターンを型として整理する場所。状況別の対応方針・介入手法・テンプレートを蓄積し、ケース対応AIが提案の元ネタとして使う。

## 格納するもの
- 状況（トリガー・文脈）→ 介入方針 → 期待される効果、という形式のパターン集
- 介入手法別のテンプレート（声かけ例、支援計画の書き方、家族への説明の仕方など）
- パターンの適用条件・禁忌（このパターンが効かない/使ってはいけない状況）
- パターンの効果検証結果（うまくいった／いかなかった事例へのリンク）

## 03・04との関係
- 03_Case_Database（生データ）と04_Expert_Judgement（判断基準）から抽出・一般化された「再利用可能な型」がここに入る
- 個別事例 → 判断の言語化 → パターンとして抽象化、という流れ

## 発展ステップとの関係
ケース対応AIが「このケースにはこのパターンが使えそうです」と提案する際の中核データ。パターンの粒度を揃えておくと、AIの提案の一貫性が上がる。

## 命名ルール（叩き台）
- `Pattern_分野_状況名.md`（例：`Pattern_就労支援_無断欠勤対応.md`）

# 06_Assessment_Framework

## 用途
管理者向け品質評価AIが用いる評価の枠組みを置く場所。支援員の対応やケースの質を「何を基準にどう評価するか」を定義する。

## 格納するもの
- 品質評価の評価軸・指標（例：アセスメントの妥当性、介入の適切性、記録の質、利用者本人の意思尊重度など）
- 評価基準・スコアリングルール、チェックリスト
- 評価結果のフィードバック文言のテンプレート
- 評価の根拠となる制度要件（02）・熟練者の判断基準（04）へのリンク

## 他フォルダとの関係
- 02_Knowledge_Base：評価基準の制度的な裏付け
- 04_Expert_Judgement：「良い対応とは何か」の暗黙知を評価基準に落とし込む際の元ネタ
- 03_Case_Database：評価対象となる実際のケース

## 発展ステップとの関係
支援員向けケース対応AIの「次」のフェーズである品質評価AIの中核。ここが整うことで、個々の対応を属人的な感覚ではなく一貫した基準で評価できるようになる。将来の福祉現場OSでは、評価結果が事業所全体の質向上サイクルに組み込まれる想定。

## 運用ルール（叩き台）
- 評価基準は「なぜその基準か」の根拠（法令・ガイドライン・熟練者の知見）を必ず紐付ける
- 基準は固定せず、運用しながら改訂履歴を残す

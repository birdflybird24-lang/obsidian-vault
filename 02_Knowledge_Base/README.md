# 02_Knowledge_Base

## 用途
制度・法令・様式・加算要件など、正規の一般知識を蓄積する場所。AIが根拠として参照する「一次情報の要約・整理」を置く。

## 格納するもの
- 関連法令（障害者総合支援法、児童福祉法、介護保険法など）の要点整理
- 報酬基準・加算要件・人員配置基準
- 各種様式・書式のテンプレートとその記入ルール
- 行政通知・Q&A・解釈通知のまとめ
- 制度改正の履歴・変更点メモ

## 発展ステップとの関係
ケース対応AIが「その対応は制度上問題ないか」を判断する際の根拠データ。品質評価AIが評価基準（06）を作る際の裏付けにもなる。

## 運用ルール（叩き台）
- 出典（法令名・条文番号・通知番号・発行日）を必ず明記する
- 制度改正があった場合は原本を残しつつ改訂履歴を追記し、99_Archiveへは移動しない（現行知識ベースとして最新性を保つ）

# 01_Domain_Model

## 用途
福祉サービスという領域そのものの構造化モデルを置く。AIが「この業界がどう成り立っているか」を理解するための土台となる知識。

## 格納するもの
- サービス種別の分類（例：就労継続支援、放課後等デイサービス、グループホーム等）とその法的根拠
- 登場人物・関係者のモデル（利用者、家族、支援員、サービス管理責任者、管理者、行政、相談支援専門員など）とその関係性
- 業務プロセスのモデル（アセスメント→個別支援計画→支援実施→モニタリング→評価のライフサイクル）
- 用語集・概念定義（オントロジーの元になるもの）

## 発展ステップとの関係
ケース対応AI・品質評価AIのどちらも「誰が」「何を」「どのプロセスで」扱っているかの共通理解が必要。ここが揺らぐと下位フォルダ（03〜06）の情報がバラバラになるため、最初に固めておきたい基盤。

## 02_Knowledge_Base との違い
- 01は「構造・関係性・概念」（＝スキーマ側）
- 02は「具体的な制度内容・様式・要件」（＝コンテンツ側）

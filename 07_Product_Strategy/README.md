# 07_Product_Strategy

## 用途
「支援員向けケース対応AI → 管理者向け品質評価AI → 福祉現場OS」というプロダクトの発展戦略を管理する場所。

## 格納するもの
- プロダクトロードマップ（各フェーズの目標・スコープ・時期）
- 各フェーズの機能要件・優先順位（MVP定義など）
- ターゲットユーザー像（支援員／管理者／事業所全体）ごとの課題・ニーズ整理
- 競合・類似サービスの調査メモ
- 収益モデル・事業計画に関わる検討事項
- KPI・成功指標の定義

## 他フォルダとの関係
01〜06で蓄積した知識・データがプロダクトの「中身」だとすれば、07はその中身を「誰に・どう届けるか」という戦略レイヤー。09_Data_Architectureとセットで、中身と実装をつなぐ役割を持つ。

## 運用ルール（叩き台）
- 意思決定は日付付きで記録し、後から「なぜこの判断をしたか」を追えるようにする
- フェーズが進んだら、旧い戦略ドキュメントは99_Archiveへ移動する

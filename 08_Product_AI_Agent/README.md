# 08_Product_AI_Agent

## 用途
「支援員向けケース対応AI」「管理者向け品質評価AI」など、実際に作るAIエージェントそのものの設計・実装関連情報を置く場所。知識・データ（01〜06）を実際に動くプロダクトへ組み上げるレイヤー。

## 格納するもの
- 各AIエージェントの役割定義（ケース対応AI／品質評価AI／将来のOS内エージェント群）
- プロンプト設計・システムプロンプト・ツール定義
- エージェントの入出力仕様（何を受け取り、何を返すか）
- 評価・テストケース（AIの回答の妥当性をどう検証するか）
- 運用中に見つかった不具合・改善ログ

## 他フォルダとの関係
- 01〜06：エージェントが参照する知識・判断基準そのもの（中身）
- 07_Product_Strategy：どのエージェントを、いつ、何のために作るかという戦略（Why/What）
- 09_Data_Architecture：エージェントが使うデータ基盤の構造（How の技術基盤）
- 08はこれらを踏まえた「エージェント自体の設計・実装」（Howの中核）

## 発展ステップとの関係
支援員向けケース対応AI → 管理者向け品質評価AI → 福祉現場OS、という各フェーズで生まれるエージェントの仕様・プロンプト・実装メモをここに集約する。将来的にOS化する際は、複数エージェントの連携設計もここに含める。

## 運用ルール（叩き台）
- エージェントごとにサブノート（`Agent_ケース対応AI.md` など）を作り、バージョン変更は履歴として残す

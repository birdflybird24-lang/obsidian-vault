# 04_Expert_Judgement

## 用途
ベテラン支援員・専門家が持つ暗黙知や判断基準を言語化して蓄積する場所。マニュアル化されにくい「勘所」「経験則」をナレッジ化する。

## 格納するもの
- 「こういう状況ではこう判断する」という経験則・判断ルール
- ベテランへのヒアリング・インタビュー記録
- 難しい判断を迫られたケースでの思考プロセスの言語化
- 新人と熟練者の判断の違いの分析

## 03_Case_Databaseとの違い
- 03は「何が起きて、何をしたか」という事実の記録
- 04は「なぜそう判断したか」という思考・判断基準の抽出物

## 発展ステップとの関係
ケース対応AIが単なる制度知識の検索エンジンではなく、熟練支援員のような「判断」を提案できるようにするための核となる知識。品質評価AI（06）の評価基準を人間の暗黙知に近づけるためにも参照する。

## 運用ルール（叩き台）
- 誰の判断か（属人化した知見）が分かるよう出典・発言者を記録する（本人の同意を得た上で）
- 判断が分かれるケースは複数の視点を併記し、単一の「正解」として断定しない

# 99_Archive

## 用途
使わなくなった情報・旧版資料・保留事項を保管する場所。削除はせず、ここに退避することで本編（00〜09）の見通しを良く保つ。

## 格納するもの
- 古いバージョンの戦略ドキュメント・評価基準・パターン集
- 検討したが採用しなかったアイデアや方針
- 制度改正前の旧い知識ベース内容（履歴として残す必要があるもの）
- 一旦保留になったケースや検討事項

## 運用ルール（叩き台）
- 移動する際は、元々どのフォルダにあったか・いつ・なぜアーカイブしたかを冒頭に記録する
- 完全に不要（参照価値ゼロ）と判断できるもの以外は、削除せずここに置く
- 定期的に見直し、本当に不要なものは削除を検討する

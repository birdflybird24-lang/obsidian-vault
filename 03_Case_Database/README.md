# 03_Case_Database

## 用途
実際の支援ケース・事例を蓄積するデータベース。ケース対応AIの学習・参照データであり、品質評価AIが評価対象とする実績データでもある。

## 格納するもの
- 個別ケースの記録（相談内容、アセスメント結果、支援方針、実施した介入、経過、結果）
- 対応履歴・支援経過記録
- ケースごとのタグ（分野、困難度、対応パターン、結果の良し悪しなど）

## 重要：個人情報の取り扱い
- 実名・住所・生年月日など個人が特定できる情報は記載しない、または必ず匿名化・仮名化してから格納する
- ケースIDで管理し、個人情報は別管理（このデータベースには含めない）とすることを推奨

## 発展ステップとの関係
- ケース対応AI：類似ケース検索・対応提案の元データ
- 品質評価AI：実際の対応の質を評価するための実績データ
- 04_Expert_Judgement・05_Intervention_Patternsの抽出元となる生データ

## 命名ルール（叩き台）
- `Case_YYYYMMDD_連番_概要.md` など、時系列で追いやすい形式
